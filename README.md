# 🚌 Route One USA

**Authentic American bus simulator built with Godot 4 C#**

> A Claude × Gemini collaboration, developed under LV333-Technologies

---

## About

Route One USA is an open-world bus simulator set in a fictional but detailed American map. Drive iconic US transit vehicles across city streets, suburbs, interstates and rural routes. Manage schedules, pick up passengers, and experience the full range of American public transit — from inner-city bus lines to long-distance coach routes.
